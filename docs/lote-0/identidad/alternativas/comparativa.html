Pacha Viva — comparativa de símbolo

Cuatro direcciones a comparar. A es el símbolo actual (barras ascendentes), copiado sin modificar para que la comparación sea justa. B, C y D son alternativas nuevas. Todas: geometría abstracta, una sola tinta, funcionan en negativo sobre foto oscura (fila inferior de cada bloque, simulada con degradado).

A — actual: barras ascendentes

Cuatro barras verticales de altura creciente. Referencia de partida: el problema a resolver es que se lee como gráfico de crecimiento (fintech/analítica).
